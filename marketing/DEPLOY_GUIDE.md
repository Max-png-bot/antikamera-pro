# Деплой АнтиКамера PRO — единственное действие владельца

Пакет готов: файл `antikamera-pro-deploy.zip` (в корне воркспейса).
Внутри всё, что нужно серверу. Склад кодов в пакет НЕ включён (чтобы коды
не попали в публичный репозиторий) — сервер создаёт коды сам при покупках.

---

## Путь А: GitHub + Render (бесплатно, ~10 минут, самый простой)

### 1. GitHub (2 мин)
1. Откройте **github.com** → кнопка **Sign up**;
2. Введите: почту → пароль → имя пользователя (например, `antikamera-dev`) →
   решите простую капчу-пазл → **Verify**;
3. Зайдите в свою почту → откройте письмо от GitHub → кнопка
   **Verify email address**.

### 2. Загрузка кода (3 мин)
1. На GitHub нажмите **+** (справа вверху) → **New repository**;
2. Имя: `antikamera-pro`, тип **Public** → **Create repository**;
3. На открывшейся странице найдите ссылку **«uploading an existing file»**,
   нажмите её;
4. Распакуйте у себя `antikamera-pro-deploy.zip` (правый клик → «Извлечь»);
5. Перетащите в окно GitHub **все файлы и папки** из распакованной папки
   (выделить все → перетащить);
6. Дождитесь загрузки → зелёная кнопка **Commit changes**.

### 3. Render — запуск сервера (4 мин)
1. Откройте **render.com** → **Get Started for Free**;
2. Нажмите **Sign up with GitHub** (тот же аккаунт, ничего нового) → **Authorize**;
3. На дашборде: **New +** (слева вверху) → **Blueprint**;
4. Выберите репозиторий `antikamera-pro` → **Apply**. Всё настроено
   автоматически (файл `render.yaml` внутри): команда запуска, порт, ключ;
5. Через 2–3 минуты сервис станет зелёным — ваш адрес:
   **https://antikamera-pro.onrender.com** — это ссылка покупателям.

### 4. Настройки после запуска (1 мин, важно)
- **Ключ панели:** сервис → вкладка **Environment** → скопируйте значение
  `ADMIN_KEY` и сохраните. Панель продавца:
  `https://antikamera-pro.onrender.com/admin?key=ВАШ_КЛЮЧ`;
- **Ключ API блокчейна (уберёт лимиты):** зайдите на **tronscan.org** →
  Account → API → создайте бесплатный ключ → в Render: Environment →
  **Add Environment Variable** → имя `TRONGRID_KEY`, значение ключа → **Save**.

### Нюансы бесплатного плана (честно)
- Сервис «засыпает» без посетителей: первый заход занимает ~минуту;
- Журнал продаж хранится в контейнере и сбрасывается при перепубликации.
  **Выручка не теряется никогда** (она в блокчейне, у вас на кошельке), но
  список «какой хэш уже использован» обнулится — редкий шанс повторного
  обмена хэша. Для полной сохранности: Render → сервис → Disks → добавить
  диск 1 ГБ с монтированием в `/app/sales` (платно, ~$1/мес) — или путь Б.

## Путь Б: VPS (одна регистрация, ~$4–5/мес, данные постоянны)

Для уверенных пользователей. Купите любой Ubuntu VPS (4+ ГБ RAM не нужен,
хватит минимума), затем:

```bash
# на своём компьютере (Windows — через PowerShell):
scp antikamera-pro-deploy.zip root@IP_СЕРВЕРА:/root/
ssh root@IP_СЕРВЕРА
apt update && apt install -y docker.io unzip
unzip antikamera-pro-deploy.zip -d akp && cd akp/antikamera-pro
docker build -t akp .
docker run -d --restart=always -p 80:8083 \
  -e ADMIN_KEY=ваш-секрет-придумайте \
  -v /root/akp-sales:/app/sales \
  --name akp akp
```

Данные продаж — в `/root/akp-sales` на сервере, переживают всё.
Домен (например, antikamera.pro) покупается отдельно у любого регистратора
и указывает на IP сервера.

## После деплоя — проверьте сами (2 мин)

1. Откройте `https://ваш-адрес/landing/` — лендинг с QR вашего кошелька;
2. Откройте `/admin?key=...` — панель: продажи, выручка, отзывы;
3. Сделайте тестовую покупку на 1 USDT (не дойдёт до выдачи — увидите
   «сумма меньше цены», так и должно быть) и одну реальную — убедитесь,
   что код пришёл автоматически.

Всё, что дальше (продажи, выдача кодов, отзывы, статистика) — происходит
само. Улучшения по отзывам — попросите ассистента «обработай отзывы
АнтиКамеры» в чате, где собирались эти файлы.
