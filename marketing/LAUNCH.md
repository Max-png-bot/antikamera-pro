# Запуск без участия владельца — что осталось из «ручного»

## Что уже работает само (можно проверить сейчас, порт 8083)

Полный цикл покупки без продавца:
1. Покупатель открывает лендинг → платит 9.9 USDT (TRC20) на кошелёк
   `TBA8d1eLJhLVKGjQfeDcxvEJTmrq7Nzrc9` по QR-коду;
2. Вставляет хэш транзакции в форму «Автоматическая выдача кода» (или прямо
   в приложении: PRO → «Код за оплату»);
3. Сервер проверяет транзакцию в блокчейне TRON (сумма ≥ 9.9, адрес, USDT,
   хэш не использован) → мгновенно выдаёт код активации;
4. Покупатель вводит код → PRO разблокируется. Продавец не участвует.

Плюс само собирается: отзывы из приложения (звёзды + текст), статистика продаж
и выручки, авто-приоритеты улучшений из негативных отзывов.
Панель: `/admin?key=<ADMIN_KEY>`.

Коды: 10 на складе; кончатся — сервер отчеканит новые сам (плата получена —
код действителен, запись в журнал продаж идёт всегда).

## Неустранимый минимум от владельца (однократно, ~10 минут)

Пошаговая инструкция с кликами — **`marketing/DEPLOY_GUIDE.md`**, готовый
пакет для загрузки — **`antikamera-pro-deploy.zip`** (в корне воркспейса;
склад кодов в пакет не включён — сервер чеканит коды сам, утечка исключена).

Причина, почему регистрация не автоматизируется: платформы (GitHub, Render,
почта) при регистрации присылают код подтверждения на почту/телефон и
ставят капчу — именно чтобы подтвердить живого человека. Доступа к чужой
почте/SMS у ассистента нет, а аккаунты, на которых крутятся деньги, должны
принадлежать владельцу (восстановление пароля, вывод средств, антифрод).

**Шаг 1. Хостинг (обязательный, 10 минут):**
- Вариант А (бесплатно, Render.com): зарегистрироваться → New Web Service →
  подключить GitHub-репозиторий с этой папкой → Render сам поднимет по
  `render.yaml` (уже готов). ADMIN_KEY сгенерирует сам; TRONGRID_KEY (бесплатный
  с tronscan.org) прописать в переменных окружения — уберёт лимиты API;
- Вариант Б (VPS от ~$4/мес, надёжнее): установить Docker →
  `docker build -t akp . && docker run -d -p 80:8083 -e ADMIN_KEY=секрет akp`
  (Dockerfile готов);
- Домен — по желанию (без него ссылки вида `site.onrender.com`).

**Шаг 2. Аккаунт для контента (если нужны Shorts/Reels):** завести один
аккаунт — выкладывать видео из `marketing/video_scripts.md` (съёмка демо-экрана
телефона, монтаж любой). Либо публиковать посты из `marketing/posts.md` руками
в чатах — контент готов текстами.

**Шаг 3. Юридическое:** доход в USDT облагается налогом вашей страны —
задекларировать при поступлениях (самозанятость/ИП упрощают это до 5 минут).

## Контур «отзывы → улучшения»

Отзывы копятся автоматически в `/admin`. Топ-проблемы формируются из слов
негативных отзывов (проверено: из тестового отзыва «не хватает pdf отчёта и
инструкции на английском» панель сама вытащила «отчёта», «инструкции»).

Цикл улучшения: зайти в чат с этим ассистентом и сказать «обработай отзывы
АнтиКамеры» — ассистент прочитает feedback.json, составит бэклог приоритетов
и внесёт изменения в приложение/сервер (код обоих доступен в этом воркспейсе).
Ваше участие — только запустить цикл фразой.

- 11 автотестов выдачи кодов: валидная оплата, повтор хэша, чужой адрес,

  ключа, приём отзывов — проверено curl'ами;
- PWA и лендинг синаксически проверены, service worker не кэширует API.
