# 💰 Реферальные ссылки бирж — доход без продаж (5 минут, один раз)

## Зачем
Наши гайды «Как купить USDT» уже бесплатно отправляют людей на биржи.
Партнёрские программы бирж платят за это: **до 30–50% от торговой комиссии
каждого приведённого пользователя — пожизненно**, у некоторых бирж есть
CPA-бонус за регистрацию/первую сделку. Это второй денежный поток поверх
продаж кодов: зарабатывает даже тот, кто только читал гайд.

Инфраструктура ГОТОВА: во всех гайдах биржи уже стоят ссылками-слотами
(`<a data-ref="bybit">` и т.д.), а значения подставляются из одного файла
`ref-links.js` (отдаётся без кэша — замена кода применяется на всём сайте
мгновенно, без передеплоя). Сейчас там обычные ссылки без кодов.

## Что нужно от владельца (только вы — аккаунты и KYC на ваше имя)
1. **Bybit** (обычно самые щедрые условия): зайти в свой аккаунт →
   «Refer / Пригласить друзей» → скопировать реферальную ссылку
   (вид: `https://www.bybit.com/invite?ref=XXXXX`).
2. **OKX**: аккаунт → «Пригласить друзей / Affiliate» → ссылка.
3. **Binance**: аккаунт → «Реферальная программа» → ссылка
   (выбрать максимальный kickback).
4. (Опционально) **Amazon Associates** для тепловизоров InfiRay/Topdon/FLIR:
   партнёрка Amazon платит 1–4% с покупки (~$100–300) — ссылки можно
   поставить в те же слоты.
5. **Прислать мне ссылки любым способом:** написать сюда в чат или телеграм-боту
   («вот моя реферальная ссылка Bybit: …») — я активирую их по всему сайту
   за один заход и пришлю подтверждение.

## Проверка после активации
- Открыть /blog/ru-usdt.html → навести на «Bybit»: ссылка должна содержать
  ваш код (`?ref=` или `/invite?ref=`).
- Пройти по ссылке с телефона — счётчик переходов появится в кабинете биржи.

## Чего мы НЕ делаем (принципиально)
- «Серые» обменники с кикбеками — противоречит нашей AML-политике
  (только лицензированные биржи: соответствует правилу «грязная крипта
  не принимается»).
- Обход запретов: в странах из запрет-листа гайдов ссылки на биржи
  не рекламируются.
